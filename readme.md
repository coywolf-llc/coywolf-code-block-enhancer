# Coywolf Code Block Enhancer

> [!IMPORTANT]
> Coywolf Code Block Enhancer is no longer developed. Coywolf moved all of its sites from WordPress to [EmDash](https://emdashcms.com), and the plugin features it still uses are now in [Coywolf Pack for EmDash](https://github.com/coywolf-llc/coywolf-pack). The plugin is closed in the WordPress.org Plugin Directory. This repository is archived and read-only.

## Use Coywolf Pack instead

Code Block Enhancer is now the [Code Blocks](https://github.com/coywolf-llc/coywolf-pack/blob/main/docs/code-blocks.md) module in Coywolf Pack. It highlights code on the server, so visitors download no highlighting script, and adds themes, language labels, copy buttons and line numbers to EmDash's code block.

To add Coywolf Pack to an EmDash site, follow its [Getting started](https://github.com/coywolf-llc/coywolf-pack#getting-started) guide.

## What this plugin did

Added syntax highlighting and a copy-to-clipboard button to the native WordPress Code block, plus a language picker in the editor sidebar.

## If you still use it

The last release, [v1.0.60](https://github.com/coywolf-llc/coywolf-code-block-enhancer/releases/tag/v1.0.60), is still available, but it won't get updates, security fixes or support. The code stays here under the GPL-2.0-or-later license.
